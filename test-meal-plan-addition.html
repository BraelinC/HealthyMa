🍽️ Meal Plan Addition Feature NEW

Add recipes to meal plans directly from Favorites and Search pages

✨ Feature Overview

What's New:

  • Green Plus (+) button on recipe cards
  • Beautiful modal for selecting meal plan slots
  • Add to existing days or create new days
  • Visual preview of recipe being added
  • Support for up to 7-day meal plans
  • Instant feedback and success notifications

🧪 Test Case 1: Adding from Favorites

Steps to Test:

  1. Navigate to the Favorites page
  2. Find any favorited recipe card
  3. Look for the green + Plus button on the card
  4. Click the Plus button to open the meal plan modal
  5. Observe the modal with two tabs:
    Existing Days
    Add New Day
  6. Select a meal slot (Breakfast, Lunch, or Dinner)
  7. Click "Add to Meal Plan" button
  8. Verify success toast notification appears

Expected Behavior:

  • Modal shows recipe preview with image and title
  • Empty slots show as "Empty Slot" in green
  • Occupied slots show the current recipe name
  • Selected slot has purple border and checkmark
  • Success message: "Recipe Added! 🎉"

🔍 Test Case 2: Adding from Search

Steps to Test:

  1. Navigate to the Search page
  2. Search for any recipe or generate a new one
  3. When a recipe card appears, locate the green Plus button
  4. Click the Plus button
  5. If no meal plan exists, use "Add New Day" tab
  6. Select meal type (Breakfast/Lunch/Dinner)
  7. Confirm the addition
  8. Navigate to home page to verify recipe was added

📋 Test Case 3: Modal Features

Modal Components to Verify:

  1. Recipe Preview Card:
    • Shows recipe image (80x80px thumbnail)
    • Displays recipe title
    • Shows cooking time badge
    • Shows cuisine type badge
  2. Existing Days Tab:
    • Lists all current meal plan days (Day 1, Day 2, etc.)
    • Shows 3 meal slots per day
    • Icons: ☕ Breakfast, ☀️ Lunch, 🌙 Dinner
    • Grayed out if slot is occupied
  3. New Day Tab:
    • Creates next sequential day number
    • Disabled if 7 days already exist
    • Shows confirmation text

⚠️ Edge Cases to Test

Important Scenarios:

1. No Existing Meal Plan: System should create a new meal plan automatically

2. Maximum Days Reached: "Add New Day" tab should be disabled after 7 days

3. Replacing Existing Recipe: Should overwrite the slot with new recipe

4. API Errors: Should show error toast with retry option

5. Missing Recipe Data: Should handle gracefully with default values

✅ Success Criteria

The feature is working correctly if:

  • Plus button appears on all recipe cards in Favorites and Search
  • Modal opens smoothly with recipe preview
  • Can select any empty slot and add recipe
  • Can create new days up to 7 total
  • Success notification appears after adding
  • Recipe appears in meal plan on home page
  • Modal closes after successful addition
  • Can add multiple recipes in sequence

🚀 Quick Test Flow

5-Minute Test Sequence:

  1. Login to the app
  2. Go to Favorites → Click Plus → Add to Day 1 Lunch
  3. Go to Search → Generate recipe → Click Plus → Add to Day 1 Dinner
  4. Try to add another recipe to Day 2 Breakfast (new day)
  5. Go to Home page → Verify all 3 recipes appear in meal plan

🎉 Feature Complete!

The meal plan addition feature is now fully integrated with both the Favorites and Search pages. Users can easily build their meal plans by clicking the green plus button on any recipe card.
